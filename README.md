# Sprint_7 — Тестирование API

# Описание проекта

В рамках 7 спринта выполнено тестирование API сервиса "Яндекс Самокат":

https://qa-scooter.praktikum-services.ru/

Реализованы автотесты для следующих ручек:

- Создание курьера
- Логин курьера
- Создание заказа
- Получение списка заказов

Тесты написаны с использованием:
- Python
- Pytest
- Requests
- Allure
